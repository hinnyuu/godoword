# auth-local（本地认证适配器）

godoword 的本地认证：用户名 + 密码（argon2id 哈希）注册登录，邀请码注册模式（首个用户自动成为管理员），
cookie 会话令牌，管理员可发起密码重置（生成重置令牌，用户持令牌自行设新密码）、禁用账户（立即撤销其会话）。
完全本地，不依赖外部身份服务。禁用账户的既有登录令牌立即失效；登录限流防爆破。

密码须 8–128 位且同时含字母与数字，区分大小写；建议再加特殊字符增强强度。重置令牌单次有效，
并发使用仅一次成功；设新密码前令牌不会被弱密码请求消耗。

后续 M4 支持 OIDC（authentik）公网身份升级，业务数据挂稳定内部 user_id，切换认证零迁移。
面向用户的账户说明待认证 UI（M1d）落地后补充。
