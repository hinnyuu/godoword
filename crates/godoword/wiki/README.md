# godoword 服务

这是应用的入口程序。M1c 已能驱动 LLM 教师对话与 speak 语音合成（经 SSE 实时推送文本与音频），
会话持久化到卷（默认 SQLite，可外接 PostgreSQL），用户 API key 静态加密，启动自动建表迁移（迁移前备份）+ 自适应降权。

账户认证已落地（auth-local：用户名密码注册登录、邀请码、首用户成管理员、cookie 会话、管理员发起密码重置令牌、禁用账户撤销会话）；
对话与 provider/key 配置经真实认证 + 对象级授权（用户级 REST 未认证 401，越权访问他人资源 404）。图形配置界面随 M1d 加入。
