# kernel（内核）

godoword 的内核实现：负责回合循环（LLM 教师对话 + speak 语音合成）、会话管理、绑定解析、
上下文预算/淘汰、用量计量、进度事件 outbox 等核心服务。适配器与教学模块通过 kernel-api 契约与内核交互，互不直接依赖。

当前 M1c + 加固：回合循环（执行/投递分离，断开 cancel/continue detach，硬超时【默认 180 秒，设置页可按自己额度调整】+ 上游重试 + 退出等待）
+ 会话/音频持久化（DB/文件系统，**对象级授权**）+ 上下文预算与 truncate/summarize 淘汰（**水位制正常路径不重复**）
+ call_log 计量 + outbox 骨架 + 存储基底（自动迁移备份、用户密钥静态加密）。
认证在 auth-local 适配器。音频默认新鲜合成；五十音标准发音 M2 起由用户用自己的 TTS 生成（一次生成永久使用，白名单复用机制）。教学模块 M2+。
可靠性：重置令牌事务单次（防 Argon2 放大）、音频写失败关闭、退出 abort+join 拒新回合与背压硬边界、淘汰原子 + summarize 计费幂等（中途失败不固化）、SessionEnded 唯一认领、管理员禁用串行化均已落地，各配失败/并发负例测试（并发与迁移回滚双后端，回合行为 SQLite）。

M1d 新增用户级服务：偏好跨设备随账户、会话虚拟路径文件夹（路径即身份，NFC 归一化防日语浊音裂文件夹，
嵌套目录树/改名子树同步/删除上移一层不删会话，改名与删除上移均有冲突预检——撞既有文件夹报可理解的错误而非服务器错误）、
会话历史元数据（标题/活跃时间/消息数）。
