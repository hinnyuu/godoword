# 用户指南

> 面向使用者的人类向文档。当前为 M0 阶段，完整功能随里程碑落地。

godoword 帮助你借助 LLM 老师学习外语（日语优先）。你自行填写 API key（BYOK），
LLM 担任教师，结合语音合成完成听说练习。

## 当前可用（M0）

M0 仅提供最小 hello 服务用于验证部署链路，尚无教学功能。

## 即将可用

- M1：配置 provider 与 key、本地账户
- M2：五十音图自适应课程、学习进度评估
- M3：对话模拟
