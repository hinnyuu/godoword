# 用户指南

> 面向使用者的人类向文档。当前为 M1d 图形界面就绪 + M2 自由对话模块落地阶段，完整教学功能随里程碑落地。

godoword 帮助你借助 LLM 老师学习外语（日语优先）。你自行填写 API key（BYOK），
LLM 担任教师，结合语音合成完成听说练习。

## godoword 想成为什么

- **你的专属 LLM 语言老师**：不是固定课程，而是 LLM 根据你的水平即时讲解、领读、纠错、出练习，结合 TTS 真人发音示范。
- **你自己掌控服务商与声音**：BYOK 自选 LLM/TTS 服务商与密钥；可选不同音色担任老师，未来支持角色扮演
  （不同角色用不同声音，音色克隆由你的 TTS 服务商提供），声音档案跨课程复用。
- **越学越懂你的自适应课程**：五十音、对话等教学模块把你的学习进度汇总给评估模块，集中分析短板、
  自动调整后续教学难度与侧重点——多个模块的反馈集中用于一份持续演进的教学方案。
- **私密且可自托管**：单容器部署在你自己的机器（podman/docker），数据存本地卷，密钥加密不出服务器；
  支持本地账户，未来可接公网 authentik 单点登录（业务数据不迁移）。
- **可美化的图形界面**：M1d 起提供 Svelte 网页界面（多语言、词级高亮跟读），界面可定制美化。

## 当前可用（M1d）

**完整图形界面**（Svelte SPA，浏览器访问即用）：注册登录、BYOK 服务商配置（预设模板一键 + 自填 key + 测试连接 + 音色试听 + 密钥编辑）、
与 LLM 教师对话（流式文本 + 实时语音 + 词级高亮跟读 + 错误分流重试 + 回合用量脚注）、会话文件夹目录树整理（嵌套/改名/移动/删除上移）、
主题自定义（明暗/强调色/自定义 CSS）+ 密度/字号/侧栏折叠/回合超时偏好跨设备随账户、默认 LLM/TTS+音色/可选摘要模型三卡片绑定、
账户自助改密、管理员（邀请码/重置令牌/禁用账户）。

内核驱动 LLM 教师对话并调用 speak 工具实时合成语音（经 SSE 推送）。数据持久化到卷（默认 SQLite，可外接 PostgreSQL），
你的 API key 静态加密存储（管理员不可读），启动自动建表迁移（迁移前备份）+ 自适应降权（bind 目录文件归宿主用户）。
本地账户（argon2id）+ 邀请码注册（首用户自动成管理员）+ cookie 会话 + 对象级授权（越权 404）。

## 即将可用

- M2：五十音图自适应课程（标准发音用你自己的 TTS 生成，一次生成永久使用）、学习进度评估（多模块反馈集中）、
  学习仪表盘 + 用量看板、手机界面适配（自由对话模块已落地：以前的会话自动归入，无需先定级即可聊）
- M2 后：用户级资产备份（导出/导入你的学习资料与音频，不含 API key）
- M3：对话模拟
- 远期：角色音色档案、对话 Markdown/HTML 渲染、STT 听说互动
