# 用户指南

> 面向使用者的人类向文档。当前为 M1c 后端就绪阶段（图形界面 M1d 落地），完整功能随里程碑落地。

godoword 帮助你借助 LLM 老师学习外语（日语优先）。你自行填写 API key（BYOK），
LLM 担任教师，结合语音合成完成听说练习。

## 当前可用（M1c）

内核驱动 LLM 教师对话并调用 speak 工具实时合成语音（经 SSE 推送）。数据持久化到卷（默认 SQLite，可外接 PostgreSQL），
你的 API key 静态加密存储，启动自动建表迁移（迁移前备份）+ 自适应降权（bind 目录文件归宿主用户）。
**本地账户已落地**：用户名密码注册登录（argon2id）、邀请码注册（首个用户自动成管理员）、cookie 会话、管理员重置密码/禁用账户。
对话与 provider/key 配置经真实认证（REST，未认证返回 401）；图形配置界面随 M1d 加入。

## 即将可用

- M1d：provider 与 key 配置界面、会话界面、认证/管理界面、Svelte 前端
- M2：五十音图自适应课程、学习进度评估、白名单音频复用 + 角色音色档案
- M3：对话模拟
