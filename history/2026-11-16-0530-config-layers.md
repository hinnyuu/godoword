# 配置双轴分层

## 背景

用户提议 webui + 配置文件 + env 三层配置。需厘清与绑定解析的关系。

## 决策

两个正交轴。来源轴（部署级配置）：env > 配置文件 /data/config.toml（GODOWORD_CONFIG 可改路径）
> 内置默认；webui 管理页只读展示生效值（脱敏），不回写 env/文件；file/env 变更需重启。
用户级配置（providers/bindings/个人资料）仅 DB + webui（多用户/动态/BYOK 决定）。
绑定解析轴（模块→用户默认）不变，与来源轴正交共存。配置文件可定义 provider 预设
（端点+适配器+建议模型，不含 key）→ 用户设置页一键模板，key 仍用户自填，BYOK 不破。

## 后果

用户 key 绝不进配置文件/env。webui 不回写部署配置（鸡生蛋/重启语义/安全）。
见 [architecture](../docs/project/architecture.md)。
