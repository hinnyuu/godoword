# M1d 合并前全量审计 + 侧重审计修复轮（缺陷≠重议）

## 背景

主开发者要求 M2 启动前先全量阅读建立心智模型，再做全量代码审计 + M1d 侧重审计（六维度：
正确性/响应式、安全/授权、契约/漂移、需求覆盖、可靠性测试锚定、文档单一事实）。
审计级全量读 docs/wiki/history/全部 crates/web/scripts/CI + git/PR 交叉验证；疑似缺陷隔离实验查证
（内存 SQLite 探针，跑完即删）；基线（M0–M1c 五轮审计不变量）确认无回归。发现按「缺陷≠重议」登记并全量修复
（主开发者拍板：全量修复后合并 + 缺陷修复同配负例测试）。

## 决策（发现与修复）

**实验确证缺陷（必修）**：
- **A 会话侧栏隐没**：rename 文件夹到新深层路径不登记祖先 + 删该文件夹→会话上移到未登记路径；
  前端树仅由登记表构建（设计 Q11「树=登记表∪会话路径前缀」未实现）→会话 UI 不可见（数据完好）。
  修复：create/rename/delete/move 祖先链登记**与改写同事务**（write_tx）；前端树=登记表∪会话路径并集。
- **B 改名冲突 500**：rename 到已存在路径→UNIQUE 落 Storage→500。修复：子树外既有路径冲突预检→Conflict(400)
  （含派生路径冲突）；改名自身=无操作成功；create_folder UNIQUE 经 is_unique_violation 区分 Conflict/Storage。
- **D 改写深度越界**：深 8 子树改名到深 4 目标→派生路径深 11>8（违反上限硬边界原则）。
  修复：改写后深度/全路径重校验→Invalid(400)，事务未应用原路径不变。
- **M7 改密错旧密误登出**：InvalidCredentials→401 触发前端 401 钩子跳登录（与 P8 上游 401 同类）。
  修复：change-password 专属映射错旧密→**403**（401 专属用户会话失效）+ 前端钩子排除 change-password 双保险。
- **M1 回放音频错位**：loadHistory 把所有 tool 音频挂到最后一条 assistant。修复：单遍构建挂**前驱** assistant。
- **G1 治理缺口**：frontend job 不在 main required checks 且 image job needs 不含 frontend（前端红可合并出镜像）。
  修复：image needs +frontend；分支保护 required contexts +frontend（gh api 已更新）。

**加固项**：F1 适配器 reqwest connect 10s/read 30s（块间隔流式安全，测试端点不无限挂起）；
F2 preview 文本≤500 字符→400 + 合成总超时 60s→504 + Usage characters/tokens 完整计量（与 speak 对称）；
F4 username 1–64/显示名≤64 校验 + invite max_uses≥1；F5 改密用户级限流；F6 存储故障→500（binding UNIQUE/provider 归属 handler 预检→400）；
F7 create_folder 错误语义区分。M2 findSeg 新建段取代理引用；M3 auto_play 多段顺序队列（引擎 onEnded + markComplete + pushedMs 时钟）；
M4 会话切换 abort 在途回合 + 懒创建后 push URL（untrack currentId 防 effect 误重置）；M5 prefs 串行保存队列 + apply 先清残留内联变量；
M6 live 未完成段禁点播（防半截播放）。folder 过滤服务端 NFC 归一化（非法→400）。

**需求覆盖补齐（对照 Q1–Q17 定案）**：Q3 三卡片补齐摘要模型卡 + 模型/音色可选（去硬编码）+ 高级矩阵完整 CRUD +
provider 编辑（换 key 不删建保绑定）+ 绑定 update 替代删建；Q4/Q12 密度/字号控件与应用 + 侧栏折叠；
Q9 usage 脚注带 token/字符数字；Q13 错误分流（settings/retry/toast/shutdown/info，core session/ux.ts 纯函数 + vitest）；
Q7 文件夹改名 UI（隐式祖先先登记再改名）；i18n 全清扫（catalog 扩充，硬编码串归零）；删除未引用 P1 spike 组件 AudioSpike。
**重试语义取舍**：retryable 重试=重发上一文本（服务端已持久失败回合用户消息，重试为新回合提交；
LLM 见重复问题——再生成语义留 M2 消息 API 演进）。
