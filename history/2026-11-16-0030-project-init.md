# 项目初始化与定位

## 背景

需要一个可长期维护的外语学习项目，借助 LLM 与语音合成 API，日语优先。

## 决策

创建公开仓库 hinnyuu/godoword，许可证 AGPL-3.0。定位为私有部署 Web 应用，
podman 容器化优先、兼容 docker。完全 BYOK：用户自填 API key，LLM 担任核心语言教师，
结合 TTS 完成听说教学（未来 STT）。

## 后果

AGPL 网络条款要求 hosted 服务向用户提供源码（UI 页脚声明 + 源码链接）。
BYOK 决定 key 管理、加密、用量计量为一等关切。见 [architecture](../docs/project/architecture.md)。
