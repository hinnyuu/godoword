# M1d P8 验收修复第二轮（对话空气泡 + 测试反馈位置）

## 背景

首轮 4 缺陷修复后复验：预设/测试连接/试听通过，但**对话回复空气泡**（text-delta 不渲染）；测试连接反馈显示在试听框旁（UX 错位）。

## 决策

- **对话空气泡（Svelte 5 runes 响应式陷阱）**：ChatView send 原将 push 前的原始 assistant 对象引用传入 streamTurn 回调，
  闭包 mutate 原始对象不触发 $state 代理更新（渲染读数组内代理副本）→ 文本累积但 UI 不刷新。
  修：push 后从 `messages[messages.length-1]` 取**代理引用**再 mutate（深响应式生效，text/reasoning/segments 皆然）。
- **测试连接反馈位置**：独立 testStatus 状态，渲染于 provider 表旁（原误用 previewStatus 显示在试听面板）。

## 后果

对话流式文本/音频/高亮正常渲染；测试反馈归位。svelte-check 0 错误/警告 + build 绿。教训：**Svelte 5 $state 数组内对象须取代理引用 mutate**
（持原始引用闭包 mutate 不响应）。详见 [status](../docs/project/status.md)。
