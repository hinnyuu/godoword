# M1d P2 实现：后端扩展 + OpenAPI schema 补全 + 契约级全量审查

## 背景

P1 前端骨架 + 音频引擎（spike 听音确认）后推进 P2 后端扩展。含**一次有界 kernel-api 契约变更**
（决策 B：5 个 REST-facing 类型加 ToSchema + utoipa 有意耦合，history 2049）→**触发契约级全量语义审查**（本条目附矩阵）。

## 决策（实现要点）

- **kernel-api（B 契约变更）**：加 utoipa 依赖；ModelInfo/VoiceInfo/ChatMessage/WordTimestamp/AudioFormat 派生 ToSchema
  （仅 derive，serde 线缆形状/trait 签名不变）。contract.md 有意耦合声明 axum/sqlx **+utoipa**，升级视为契约变更。
- **0005 迁移**：user_preferences(user_id PK,prefs_json,updated_at) + session_folders(id,user_id,module_id,path,
  UNIQUE(user_id,module_id,path)，path NOT NULL 避 NULL 陷阱) + sessions.path TEXT。
- **kernel path.rs**：NFC 归一化（unicode-normalization，日语浊音陷阱）+ 固定上限校验（深度≤8/段≤64/全路径≤1024，
  协议级常量不进 config，校验仅写入时已存数据永不回溯失效）+ is_within/rewrite_prefix/parent/depth helpers（Rust 侧前缀匹配不用 LIKE）。
  8 单测（含 NFD→NFC か+゙→が）。
- **kernel preferences.rs**：Preferences typed（ToSchema）+ get/put UPSERT（ON CONFLICT DO UPDATE，last-write-wins）。
- **kernel folders.rs**：Folder/FolderError + CRUD（create 归一化+UNIQUE 冲突 / rename 子树文件夹+会话前缀批量改写单事务防环 /
  delete 子树上移一层绝不删会话 / move_session 自取命名空间+ensure_chain 自动注册路径链）；读薄分发宏、写驱动专属事务。
- **kernel session_meta.rs**：SessionListItem（title 首条用户消息截断/last_active=MAX(messages.created_at)/count/path）+
  list_sessions_meta（SQL GROUP BY 聚合 + Rust 首条消息/前缀/模块过滤）+ get_session_path。
- **auth-local**：change_password（验旧密联查 status→validate_password→事务改密 rows==1→撤销其他会话保留当前 token_hash!=current）+
  update_display_name + UserInfo ToSchema。
- **godoword REST**：prefs/folders 新模块 + rest（sessions 元数据列表/move/audio-meta）+ settings（preview 试听计量+缓存失败关闭）+
  auth（change-password/PUT me，me/admin_users/register/login 类型化 UserInfo）；main 路由注册；
  OpenAPI 注册全部新路径+schema（kernel-api 5 类型+UserInfo+新 DTO）+tags（folders/preferences）+models/voices 响应 typed。
  godoword 不引 sqlx 直接依赖——SQL 收口 kernel helper（get_session_path/move_session 自取 module）。
- **测试**：storage 迁移计数 4→5；tests/m1d.rs 双后端（偏好 UPSERT/文件夹归一化/UNIQUE/子树改写/删非空上移/移动注册/防环/越权/会话元数据过滤）；
  auth-local change_password（错旧密/弱密码不撤销/成功保留当前撤销其他/新旧密码）。全 workspace SQLite 绿（kernel 28/auth 3/m1d 1/storage 4），
  clippy -D warnings + fmt 净；PG 双后端 + cargo-deny（unicode-normalization MIT/Apache 白名单）以 CI 为准。
