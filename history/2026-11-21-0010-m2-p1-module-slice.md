# M2 P1 风险前置切片实现（注册表 + ModuleContext + 回合接线 + teach-free 端到端）+ 契约级全量审查

## 背景

前置修复 PR #24 合并（9dc5cdf，history 2130）后启动 P1。B3/B7 已定案（history 2130）：
session_id→Option<SessionId> / plan_version→u32 INTEGER / YAML→noyalib 0.0.63。
本 phase 落契约新增（触发**契约级全量语义审查 + 二审**，conventions 制度化），
跑通模块会话端到端（风险前置垂直切片，承 M1a 姿态）。

## 决策

### 契约新增（kernel-api，有界）

- `ModuleContext::session_id() -> Option<SessionId>`（B3a：for_user=None，与 ProgressEvent.session_id 一致；
  需会话方法对 None fail-closed）。
- `ModuleContext::llm(role, ChatRequest) -> ChatStream`：kernel 中介（绑定解析带 module_id，**model 由绑定填 req.model 忽略**，
  流终止全计量 call_log module 归因；模块中途弃流不记——与主回合同语义，P6 一致性检查覆盖）。
- `ModuleContext::complete_session() -> bool`：完成≠删除（completed_at + session-ended 同事务，条件 UPDATE 唯一认领，
  幂等重复 false，并发恰一个事件）；转录保留触发提取。**DELETE 不发事件翻转仍 P2**（B2 守原裁决，P3 前无消费者）。
- `ModuleContext::get_or_synthesize(key, TtsRequest) -> AssetAudio`：白名单缓存合成（UX-A3）。命中持久资产直供
  （cache_hit=true 零上游零计量）；miss 合成→/data/assets 原子写→登记 upsert（RETURNING 胜者，败者清孤儿）→计量。
  作用域 user+module+key+adapter_id+base_url+voice+model；换音色/服务商懒再生旧版保留；卷损毁文件缺失→懒再生；
  无 TTS 绑定 Unconfigured（模块降级）。`AssetAudio{audio_id,pcm,words,format,sample_rate,cache_hit}`（非 REST-facing）。
- `ModuleContextFactory`（for_session/for_user）：每模块一实例 module_id 构造期绑定，组合根注入，routes() 签名不动。
- `ModuleKind::Kernel` 变体（kernel/module.yaml kind=kernel 反序列化）。
- `ProgressEvent.difficulty: Option<f32>`（**契约形状新增**，B1 诚实标注；serde default 旧信封兼容）。
  **trait emit_progress(ProgressInput) 签名不动**（ProgressInput 早含三字段；变的是 kernel journal 内部函数 + DB 列）。

### kernel 实现

- **注册表**（registry.rs）：noyalib 反序列化 module.yaml（B7：0.0.63 精确 pin，default-features=false+std，
  MSRV 1.89→workspace rust-version 1.85→1.89）；校验 kind=teaching/id 一致/重复拒绝；RegisteredModule{manifest,module,factory}。
- **ModuleContext 实现 + 工厂**（module_ctx.rs）：KernelCtxFactory/KernelCtx；llm 计量包裹流；
  current_plan 路由 PlanProvider（无注册恒 None）；complete_session/get_or_synthesize 如上。
- **持久资产区**（assets.rs）：AssetStore（/data/assets + audio_assets 登记表）；原子写 tmp+rename；豁免淘汰（与 cache 正交）。
- **回合接线**（runtime.rs）：with_modules/with_plan_provider；注册表取 persona/工具/ctx 工厂分发（speak kernel 统一）；
  绑定解析带 module_id（主 LLM/summarizer/speak 全路径）；方案钉住（每回合取当前方案 teacher_prompt 入系统提示词 +
  set_plan_version 写会话 + RunStart.plan_version；读失败 persona-only 降级 warn）；有注册表时模块缺失/未注册 fail-closed；
  无注册表=测试路径 legacy 默认教师（persona.rs 降 legacy 兜底，**T4 生产回归**：权威 persona 在 teach-free）。
- **0006 迁移**（m2_module_slice）：plan_version TEXT→INTEGER（DROP+ADD，列从未写入零数据风险，B3b）+ completed_at +
  call_log.module_id（B4）+ progress_events outcome/item_ref/difficulty（REAL↔f32，B1）+
  **teach-free 数据迁移**（NULL 会话/default 文件夹→teach-free，T4/B8；bindings `*` 不动）+ audio_assets 登记表。
  journal：emit_progress 收 ProgressInput 落结构化列；OutboxEvent 补列 + created_at；complete_session/set_plan_version 新增。
  **模块迁移 runner 仍 P2/P3**（teach-free 无私有表，迁移走 kernel 0006；首个 runner 消费者 assess）。
- **phase 边界调整**（roadmap 落档）：P1 自带 0006 + complete_session + cached-synthesis 机制；P2 其余基底顺延 0007。

### teach-free crate + 组合根

- teach-free：PERSONA（原 kernel 默认教师移入，权威）+ module_yaml() include_str 单一事实源 + TeachingModule
  （无专属工具/无路由 P1/handle_event 空）；feature `teach-free` default-on。
- godoword：AssetStore + ModuleRegistry + KernelCtxFactory 构造注入；Runtime.with_modules；
  `GET /api/v1/modules` + `POST /sessions/{id}/complete`（200/409 幂等/404 越权）+ 模块路由 nest（先 with_state 再 nest，
  CSRF 层最后包裹）；create_session module_id 校验（未注册 400）+ 缺省 teach-free + on_session_start 失败关闭回滚；
  FolderQuery 默认 teach-free；binding module_id 注册表校验（`*` 或已注册）；init 建 assets 目录。
- OpenAPI 再生（modules/complete/ModuleListItem/ModuleListResp/CreateSessionReq.module_id）+ schema.d.ts freshness。
- 冒烟扩展：modules 清单/缺省模块/未注册 400/完成 200+409/越权 404/assets 目录。
