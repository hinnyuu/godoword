# M1c-hardening：第三方审计驱动的收尾加固

## 背景

M1c 合并（3c4dc0b）后，主开发者委托一台全新机器的独立第三方 agent 审计（/tmp/godoword_M1c_AGENTS第三方审计意见.md）。
审计肯定入口框架与实现实体，但指出**"实现存在 ≠ 里程碑语义/授权边界/交接真实性完成"**：M1c 签收过早，
存在高严重度授权/数据完整性缺陷与文档/门禁漂移。主开发者定案：**插入 M1c-hardening 加固子里程碑，全部本期修
（避免延期登记带来新漂移），M1d 讨论暂缓至加固后**。本条目登记审计发现与修复（修正事实，非重议已定设计）。

## 决策

**审计核实属实的关键发现**：
- C1【高】session/audio 只验登录不验归属（REST 丢弃 AuthUser，DbSessions 按 id 查询）→ 跨用户读/删/写/取消/回放。
- C2【高】binding 可引用他人 provider 并解密用其 key/额度（入口/解析无归属校验）。
- C3【高】禁用账户旧 cookie 仍有效（validate_session 不查 status，set_user_status 不撤销会话）+ 无管理员状态路由。
- C4【高】持久化失败被吞（create/append let _ =）→ 假成功 + 未授权上游计费。
- C5–C9 continue 无公开配置入口、cancel/timeout 非硬边界 + 无 WAL checkpoint、淘汰无水位（重复摘要/outbox）、
  设计漂移（重置未 token 化/限流无 IP/SessionEnded 未发/上游无重试）、provider_models 未计量。
- C10 smoke 过度声明（PR 称覆盖限流但脚本无 429 断言）。
- D1–D9 文档漂移（roadmap 表自相矛盾/README/web M0/module.yaml/rustdoc/OpenAPI 503 残留/PR 模板缺清理列）
  + **门禁实现缺陷 D6（kernel-api 跨模块规则不可达 + crates/*/docs/ 通配恒 false）/D7（migration/web 盲区）**。

**修复（全部本期）**：
- H1（P0）：SessionRepo/AudioCache 接缝全路径携带 user_id 对象级授权（DbSessions/MemSessions/FsAudio，get 校验 owner）；
  runtime 持久化失败关闭（meta/history/append 错误中止不调计费上游）；binding/provider 同主（入口 + resolve 解密带 user 条件）；
  validate_session 联查 active + 禁用/重置撤销会话 + is_admin 须 active + 管理员状态路由（防自禁/防禁最后管理员）。两用户负例（repo + REST）。
- H2（P1）：C5 create_session 公开 on_disconnect/params；C6 硬超时（timeout 包裹执行体）+ TTS 流 cancel + detached 退出屏障
  （tasks 注册 + shutdown 有界等待 + SQLite WAL checkpoint）；C7 淘汰水位（0003 sessions.summary/evicted_up_to，滚动摘要 + 水位推进 + outbox 一次）；
  C8 重置 token 化（tokens 单次）+ IP 限流 + SessionEnded + 上游退避重试（LLM/TTS bounded 2）；C9 测试端点计量。
- H3：OpenAPI 清 503/dev-bypass 改 401 + 403/CSRF 表达 + SSE 精确表述（path 入/事件 schema 不入）。
- H4：全状态面 reconcile（roadmap 表/README/web/wiki/module.yaml/rustdoc/PR 模板清理列）；**门禁 D6/D7 修复**
  （项目规则匹配所有变更文件 + 通配目录逐模块展开前缀匹配 + migrations/web 纳入 coverage/omission/status）+ 合成回归测试 test_gate.py。

**教训**：单用户 happy-path 测试 + CI 绿被过度概括为"功能完整无阻塞"；里程碑收尾缺"代码—设计—测试—当前事实"交叉核对。
门禁机械规则须验证真实可达（声明的规则不等于执行的规则）。加固确立子里程碑收尾定向核对纪律（H5）。

## 后果

M1c 授权边界/数据完整性/硬边界/计量补齐，文档/门禁漂移修复，多用户负例 + 门禁回归锚定。
dev-debt T1/T2 已回归（M1c）。M1c-hardening 完成后恢复"M1c 收尾完成无阻塞"，M1d 设计讨论接续。
