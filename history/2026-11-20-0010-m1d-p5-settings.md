# M1d P5 实现：设置 UI（provider/绑定/音色试听/主题/偏好）

## 背景

P4 shell 认证/管理/引导后推进 P5 设置 UI（BYOK 配置核心界面）。设计依据 history 2049（Q2 试听/Q3 三卡片+高级矩阵/Q4 主题引擎）。

## 决策（实现要点）

Settings.svelte 单页分区：
- **简化三卡片**（Q3）：默认 LLM / 默认 TTS（+音色），选服务商即写 `*` 绑定（删旧建新）；显示当前绑定 model/voice。
- **音色试听**（Q2）：选 TTS 服务商→拉音色列表→选音色+可选自定义文本→previewVoice 合成→getAudioMeta+getAudioPcm→AudioEngine 播放。
- **主题面板**（Q4）：预设切换（明/暗）+ 强调色（color picker→theme_vars）+ 自定义 CSS（textarea→custom_css）+ 一键重置；经 prefs.update 跨设备保存+即时应用。
- **偏好开关**：auto_play / on_disconnect_default（continue 明示消耗额度）。
- **provider 管理**：预设模板一键填充（config.provider_presets）+ 自定义（adapter/label/base_url/key）+ 测试连接（models）+ 删除；key 不回显提示。
- **高级绑定矩阵**（折叠）：完整 bindings 表（module/cap/role/model）+ 删除。
- 类型修正：生成可选字段 `T|null`（exactOptionalPropertyTypes 清字段用 null 非 undefined）；params_json cast 取 voice；table tr 须 tbody。

## 后果

设置 UI 就绪（BYOK 三卡片最短路径 + 高级矩阵不丢模块化能力 + 试听闭环 + 主题自定义跨设备）。
svelte-check 0 错误/警告 + vite build 绿。P6 会话 UI（对话/文件夹树/音频/高亮）→ P7 构建/CI → P8 验收。
