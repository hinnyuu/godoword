# M1d P6+P7 实现：会话 UI（对话/文件夹树/音频高亮）+ Dockerfile node 构建/SPA 伺服

## 背景

P5 设置 UI 后推进 P6 会话 UI（核心产品面）+ P7 构建/部署。设计依据 history 2049（Q1 播放/Q7 文件夹/Q11 虚拟路径/P22 SSE）。

## 决策（实现要点）

- **ChatView.svelte**（对话核心）：streamTurn SSE 流式（text-delta/reasoning-delta 累积入 assistant 消息，$state 深响应）；
  audio-start/chunk/word-timestamps/audio-end 累积音频段（chunks b64 + words）；auto_play 偏好→audio-end 自动播放，否则手动点播；
  AudioEngine 播放（live 推 chunks / 回放拉 getAudioPcm+getAudioMeta）+ onHighlight 词级高亮（active 段 words 渲染 active class）；
  reasoning 默认折叠可展开；error 按 action 分流（settings→去设置链接）；usage 脚注；cancel（AbortController + cancelSession）；
  历史加载 getSession（tool 消息 content 提取 audio_id 补回放段）。
- **SessionSidebar.svelte**：buildTree 文件夹目录树（递归 snippet 渲染，折叠态）+ 会话元数据列表（按 path 分组 + 未分类）；
  新建会话（on_disconnect 偏好）/打开（push /chat/:id）/删除（confirm）/移动（prompt 路径）/新建文件夹/删文件夹（上移一层提示）。
- **Home.svelte**（侧栏+ChatView，路由 '/' 新建会话跳 /chat/:id，'/chat/:id' 现有）+ **Sessions.svelte**（管理页）。App 加 /chat/:id 路由。
- **P7 Dockerfile 三阶段**：rust builder（cargo release）+ node:22-slim webbuilder（npm ci workspaces→vite build）+
  debian-slim 运行时（dist 拷入 web/shell/public）；陈旧 M0 root 注释修正（自适应降权 M1b 已落）。.dockerignore 加 web/**/dist。
  **hash 路由（svelte-spa-router）深链不 hit server，免 SPA fallback**。
- **冒烟扩展**：SPA 伺服断言（title + /assets/index- 引用）；meta milestone M1c→M1d（rest.rs + smoke）。
- **验证**：core tsc + vitest 32；shell svelte-check 0 错误/警告 + vite build 绿（157KB）；cargo check + fmt 净。
  a11y 修正（folder-name button）；exactOptional 清字段 null；recursive snippet 目录树。image node 构建以 CI 为准。

部署矩阵重 sign-off（Dockerfile 变更）+ R4 main 重测 + 全状态面 reconcile。详见 [status](../docs/project/status.md)、
