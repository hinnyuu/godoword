# M1d P3 实现：web/core 领域核心接线（api/sse/session/theme/i18n/prefs）

## 背景

P2 后端扩展 + OpenAPI schema 补全（CI 全绿含 PG 双后端 + cargo-deny）后推进 P3 web/core。
承 history 0330 分层纪律：领域逻辑不进组件，shell 调 core 域函数。设计依据 history 2049。

## 决策（实现要点）

- **api**：openapi-typescript 从 committed `src/api/openapi.json`（P2 后端快照，32 路径/37 schema）生成 `schema.d.ts`（提交）；
  openapi-fetch 类型化客户端（同源 cookie，CSRF middleware 自动注入 X-Requested-With + 401 onUnauthorized 钩子）。
  **CI freshness 锚**：frontend job `gen:api + git diff --exit-code schema.d.ts`（重生成比对，类比 gate --check-index）。
  变更请求 OpenAPI 标 CSRF header required→生成类型强制 params.header；core 域函数封装（shell 不裸调 api）。
- **sse**：fetch ReadableStream + eventsource-parser（POST→SSE，EventSource 仅 GET 不可用）；SessionEvent 判别联合
  （event 标签 + 载荷扁平化，镜像 kernel-api serde）；parseSessionEvent + streamTurn（signal 中止）；重连=重附持久态（shell）。
- **session/path**：normalizePath（String.normalize NFC 镜像 + 上限校验）+ buildTree（trie 目录树）+ isWithin（段边界）。
- **theme/engine**：PRESETS（明/暗）+ mergeVars（用户覆盖）+ applyTheme/clearCustomVars（DOM CSS 变量）。
- **i18n**：zh-CN catalog（按域分组，第一天外部化，svelte-i18n shell 注册）；en 后置。
- **prefs/store**：loadPreferences/savePreferences 域函数（生成 Preferences 类型，PUT 显式 CSRF header param）。
- **测试**：vitest 32（audio 18 + path 6 + theme 3 + sse 5）；core tsc + shell svelte-check 0 错误 + vite build 绿（127 模块）。

## 后果

web/core 领域核心就绪（api 类型单一事实源 + freshness 机械锚 / SSE / 路径 / 主题 / i18n / 偏好），shell P4–P6 调域函数铺 UI。
